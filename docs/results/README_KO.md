## 1단계 — Lie-GNN + DIAMOND 세계 모델

### 1.1 2018년 GraphCast 비교 (`stage1_world_model/graphcast_2018/`)

- **학습:** 2015–2017년 ERA5, `lie_diffusion` + `chain` 결합, 파라미터 0.74M, CPU로 약 1.1시간.
- **평가:** 2018년, 6일 간격 00 UTC 초기 시각 61개, lead 6–120h, 앙상블 멤버 4개.
- **GraphCast:** WB2 0.25° 예측을 64×32로 면적 보존 평균했습니다.

| 지표 | 값 |
|---|---|
| 72h z500 RMSE, 우리 / GraphCast | 830 / 112 m²/s² (약 7.4배) |
| 72h 전체 변수 중앙값, 우리 ÷ GraphCast | 약 4.3배 |
| persistence보다 나은 변수·lead 쌍 | 6h 40%, 24–72h 88%, 96–120h 61% |
| 기후값보다 나은 변수 | 72h 2%, 120h 0% |
| 앙상블 spread/skill (72h 중앙값) | 0.34 (과신) |

GraphCast는 1979–2017년, TPU 32개, 0.25°로 학습했으므로 예산 차이가 매우 큽니다. 6h에서 지는 것은 인코더→디코더 복원 오차 바닥 때문입니다.

### 1.2 쉘 결합 절제 실험: chain vs independent (`stage1_world_model/ablation_2018/`)

같은 설정(2100 스텝)으로 `shell_coupling: independent`를 학습하고, 1.1과 같은 61개 초기 시각에서 평가했습니다. 변화율은 (independent − chain) / chain입니다.

| 83개 변수 × 20 lead 평균 | independent |
|---|---|
| 앙상블 평균 RMSE | **−0.74%** (변수·lead 쌍의 58% 개선) |
| 멤버 1개 RMSE | −0.64% (56% 개선) |
| CRPS | −1.17% |
| spread/skill 중앙값 (chain 0.34) | 0.35 |

- 대표 변수: z500 RMSE 6h −9.4%, 24h −3.0%, 72h −0.8%, 120h −4.6%; T850 120h −10.6%. 반면 T2m +3.9%(6h) ~ +10.1%(120h), U850 24–72h 약 +2%로 지표 변수는 chain이 다소 낫습니다.
- **판정:** 이 규모에서는 쉘 간 사슬 결합이 이득을 주지 못했고 독립형이 근소하게 낫습니다. 차이는 작고 변수별로 엇갈려 61개 초기 시각의 변동 범위 안으로 봐야 합니다. 지네형 가설은 대규모(0.25°, GPU) 학습에서 다시 판정합니다.

### 1.3 용량 점검: 규모의 문제인가 (`stage1_world_model/scaling/`)

**질문 (감자, 10/31 16:15):** 모든 팔이 72h z500에서 GraphCast보다 약 7배 나쁘고 72h 뒤로는 기후값을 넘지 못합니다. 이것이 가설의 문제인지, 규모(파라미터 0.74M; 2015–17 학습 창 4380개에 배치 2 × 2100 스텝 ≈ 1 epoch)의 문제인지 먼저 가립니다. 새 가설이 아니라 원인 분석이므로 단계를 나누지 않습니다.

**팔 (S = 1.2의 independent, 같은 데이터·같은 평가):** W2 = 모든 feature 폭 2배(2.9M), W4 = 폭 4배(11.4M; 메모리 때문에 데이터를 디스크에서 읽음), L2 = S 폭에 모든 단계의 스텝 2배(학습 길이 대조군). 평가는 5단계 원인 분석과 같은 31개 초기 시각, 72h 단일 멤버 오차 분해(자동부호화기 바닥 + 잠재 동역학)와 denoiser knock-out입니다. 설정: `configs/wb2_scale_w2.yaml`, `wb2_scale_w4.yaml`, `wb2_scale_l2.yaml`.

**판정 규칙(사전 등록):** (1) W2·W4가 72h z500 RMSE를 S보다 5% 이상 낮추고 구간이 0을 포함하지 않으면 용량이 한계입니다. (2) L2가 W2만큼 또는 더 줄이면 용량보다 학습량(1 epoch)이 한계입니다. (3) 셋 다 72h에서 3% 미만이면 이 데이터(3년, 5.625°)와 구조에서는 규모를 키워도 72h가 바뀌지 않으므로, 데이터 쪽(감자 클러스터의 39년 0.25°)이 먼저입니다. 6h는 자동부호화기 바닥, 72h는 잠재 동역학 몫으로 나눠 어느 쪽이 규모에 반응하는지도 기록합니다.

## 2단계 — 새 데이터로 world model 보강 (`stage2_rl_refinement/`)

**설정:**
- 1단계의 2015–2017년 모델을 2018–2019년 새 데이터로 150 step 미세조정했습니다.
- 학습한 것은 DIAMOND denoiser(정책)뿐이고, 나머지는 고정했습니다.
- 2020년 31개 초기 시각에서 test했습니다. 세 모델 모두 같은 초기 시각입니다.

**두 가지 방법:**
- **지도학습 대조군:** stochastic 단계 손실(K=4 rollout)만 씁니다.
- **RL (검증 보상 정책 개선):**
  - 초기 상태마다 M=4 멤버로 K=4 step rollout을 만들고, 보상은 −(GraphCast 가중 MSE)입니다.
  - GRPO식 그룹 정규화 이점으로 가중한 EDM 회귀를 합니다.
  - 같은 지도학습 손실을 anchor로 더합니다.

| 기본 모델 대비 (83개 변수 × 20 lead 평균) | 지도학습 | RL |
|---|---|---|
| 앙상블 평균 RMSE | −0.11% (53% 개선) | **−0.57%** (73% 개선) |
| 멤버 1개 RMSE | +0.42% (34% 개선) | **−1.37%** (90% 개선) |
| CRPS | **−1.22%** | +1.83% |
| spread/skill 중앙값 (기본 0.34) | **0.36** | 0.29 |

**해석:**
- RL은 각 멤버를 정답 쪽으로 당겨 결정론적 정확도를 높였습니다. 효과는 lead가 길수록 커서, 120h 멤버 RMSE는 −1.7%입니다.
- 대신 앙상블 퍼짐이 약 13% 줄어 확률 예측(CRPS)은 나빠졌습니다. 멤버별 MSE 보상은 평균에 가까운 표본을 선호하므로, 이미 과신하던 앙상블이 더 좁아졌습니다.
- 지도학습은 반대로 퍼짐을 조금 넓혀 CRPS를 개선했습니다. 결정론적 정확도는 그대로입니다.
- 두 방법 모두 GraphCast와의 차이에 비하면 효과가 작습니다(2% 미만). 고정된 Lie 구조 전이가 평균 궤적을 정하기 때문입니다.
- 초기 시각이 31개이고 부트스트랩 신뢰구간은 계산하지 않았습니다. 다만 RL의 멤버 개선(90%)과 퍼짐 감소(모든 lead에서 −12~−13%)는 변수와 lead 전반에서 일관됩니다.

**이 단계의 후속 후보 (세부 수정):**
- 보상을 그룹 단위의 적정 점수(fair CRPS)로 바꿉니다. 멤버 m의 보상을 −(|x_m − y| − Σ_j |x_m − x_j| / (2(M−1)))로 두면 정확도와 다양성을 함께 보상합니다.
- RL 단계에서 구조 전이(Lie 생성기)도 함께 학습합니다.

## 3단계 — World Theory Model (`stage3_theory/`)

**가설:** 관측 쌍 (Z_t, Z_{t+6h})의 변화를 예측하는 대신, 공유 어휘(codebook)의 원시 연산을 조합한 가장 짧은 프로그램으로 **설명**한다(Baek et al. 2026, "Learning to Theorize the World from Observation"). 원시 연산은 so(3) 원소이므로 실행기는 고정된 군 작용이고 합성은 닫혀 있습니다. 설계 문서(한국어): https://claude.ai/artifact/UW5M3kDK6rgze7xjT3ivPV

**구현 (`models/theory.py`, `eval/transfer.py`):**
- 전이 `lie_program`: 목표 조건부 프로그래머가 (쉘, 패치)마다 한 원시 연산을 제안 → EMA 벡터 양자화(코드 0 = 항등) → 군 작용 실행 → 패치별 MDL로 길이 k* 선택. `codebook_size: 0`이면 연속 프로그램(대조군 Cont-Mono).
- `theory` 학습 단계: 인코더·디코더는 1단계 체크포인트로 고정, 프로그래머와 어휘만 학습. 모든 접두 프로그램을 목표로 당기고 MDL은 선택만 합니다.
- 평가 `scripts/eval_transfer.py`: 자기 설명력(persistence·복원 바닥 대비), 유사 상태 전이(delta copy·무작위 프로그램·oracle 대비), 12시간 쌍의 길이 일반화.

### 3.1 1차 실험: C = VQ-Lie(어휘 16, K=3) vs A' = 연속 프로그램 (`stage3_theory/phase1_vq_lie_vs_continuous.md`)

2018년 6h 쌍 183개(4일 간격), 같은 고정 인코더·디코더(1단계 체크포인트), 각 1500스텝(CPU 약 55분).

| 지표 | C (VQ-Lie) | A' (연속) |
|---|---|---|
| 설명 가능한 변화 중 설명한 비율 (persistence 0.764 → 복원 바닥 0.530) | 45.2% | **48.5%** |
| 평균 프로그램 길이 k* | 2.16 | 2.69 |
| 유사 상태 전이 손실 (oracle 대비 이득) | 0.653 (0.84) | **0.645 (0.86)** |
| 무작위 프로그램 손실 (대조군) | 0.661 | 0.652 |
| 12h 쌍, K=6 설명 손실 (persistence 1.398, 바닥 0.553) | 0.976 | **0.953** |

- **판정:** 이산 Lie 어휘가 전이·일반화를 개선한다는 가설 1은 이 규모에서 지지되지 않습니다. 연속 프로그램이 모든 지표에서 2~3%p 낫습니다. 이산화의 이득은 압축뿐입니다((쉘, 패치, 스텝)당 4비트로 전이 성능의 97% 유지).
- 두 모델 모두 **무작위 프로그램이 전이 프로그램과 거의 같습니다**. 어휘가 잡은 것은 전역 공통 운동(평균류 이송)이고, 상태 특이적 기제는 persistence→oracle 격차의 약 7%입니다. 2차의 질문은 물리 코드가 이 generic 격차를 메우는지입니다.
- 6h로만 학습한 프로그램을 12h 쌍에 6스텝까지 합성하면 설명이 더 좋아져(길이 OOD) 합성 구조 자체는 유효합니다.

### 3.2 2차 실험: Lie 위의 잔차 physics 코드 (`stage3_theory/phase2_physics_codes.md`)

V = V_Lie + V_phys + V_noise 분해(수치예보의 역학 코어 + 모수화 분할)를 따라, Lie 스텝 뒤에 칼럼 국소 physics 코드(복사·수직 혼합(플럭스 형태, 보존)·지표 교환)를 실행합니다(`models/physics_codes.py`). 같은 2018년 6h 쌍 183개, 같은 고정 인코더·디코더, 각 1500스텝.

- E1 = hybrid(Lie 16 + physics 15), 게이트 없음: 양자화기가 항등 코드를 고르지 않아 모든 패치에 매 스텝 physics가 들어가 Lie 프로그램을 방해했습니다.
- E2 = E1 + (쉘, 패치)별 학습 게이트(시그모이드, 닫힌 상태로 시작해 C와 같은 모델에서 출발).
- D = physics-only(Lie 어휘는 항등만).

| 지표 | C (VQ-Lie) | E1 | **E2** | D |
|---|---|---|---|---|
| 설명한 비율 (persistence 0.764 → 바닥 0.530) | **45.2%** | 34.0% | 44.7% | 14.1% |
| 평균 프로그램 길이 k* | 2.16 | 0.85 | 1.51 | 0.87 |

## 4단계 — 그래프 V-Net so(3) 피라미드 (`stage4_pyramid/`)

**가설:** 정이십면체 계층(레벨 1/2/3 = 42/162/642 노드)을 그래프 V-Net처럼 수축·확장하면서 Lie 대수를 레벨별로 다운스케일한 so(3) 피라미드(ω⁽⁰⁾ 12패치, δ⁽¹⁾ 42, δ⁽²⁾ 162) 위에서 세계 모델을 학습하면, 전역 공통 운동(거친 레벨)과 상태 특이 기제(미세 레벨)가 구조적으로 분리되어 전이가 나아지고 72–120h 롤아웃이 안정된다. 3단계 1차의 "무작위 프로그램 ≈ 전이 프로그램"이 동기입니다. 설계 문서(한국어): https://claude.ai/artifact/HyDfQMgse2dCX9CHhku21j

**구현 (`models/pyramid_graphs.py`, `vnet.py`, `pyramid_transition.py`, `eval/pyramid.py`):**
- 잠재 상태는 레벨 1·2·3 노드를 쌓은 846개 노드에 있습니다(P−skip은 레벨 1의 42개만). 전이·잔차·DIAMOND denoiser는 쌓인 노드 집합(레벨별 다중메시 + 부모–자식 엣지) 위에서 그대로 돌아갑니다.
- 인코더(수축)는 GraphCast 규칙을 레벨마다 적용합니다: 레벨 ℓ 노드는 풀링된 ℓ+1 상태에 더해 반경 0.6 × (레벨 ℓ 변 길이)의 격자점을 직접 합칩니다. 디코더(확장)는 가장 거친 상태에서 포함 삼각형으로 올라오며 레벨 상태를 skip으로 받고, 학습 중 확률 0.5로 skip을 끊습니다.
- so(3) 피라미드 전이: 쌓인 그래프 위의 Shell-GNN 하나가 속도장을 내고, 계층적 Killing 사영(부모 원소를 사전값으로, 작은 패치가 못 보는 축 방향 성분 보완)으로 ω⁽⁰⁾, δ⁽¹⁾, δ⁽²⁾를 얻어 스케일 사슬 g = exp(ω⁽⁰⁾)exp(δ⁽¹⁾)exp(δ⁽²⁾)로 모든 레벨을 이송합니다. 세부 회전은 joint 벌칙, latent 손실은 레벨 가중(1.0/0.5/0.25).
- 평가 `scripts/eval_pyramid.py` + `report_pyramid.py`: 레벨별 회전 에너지(위도대·쉘별), 레벨별 유사 상태 전이(거친/미세 레벨을 섞어 실행, 무작위 쌍 대조), 1단계 GraphCast 프로토콜과 결합한 S·P·P−skip 스코어카드.

**검증할 예측:** (1) 거친 레벨 회전의 전이 이득은 무작위 대비 크고(격차 ≥ 0.2) 미세 레벨은 작다(< 0.1); (2) 레벨별 에너지는 L0 > L1 > L2, L2는 중위도 > 열대; (3) P는 S(1단계 independent)보다 72–120h z500 RMSE가 낮고 ACC가 높다.

## 5단계 — 현실 정합 인과 Lie 세계 모델 (`stage5_causal_lie/`)

**가설:** 대기 방정식 dX/dt = F(X)의 각 항은 벡터장, 곧 Lie 대수의 생성자이고, exp(Δt F)는 군 원소, 순차적 과정은 군의 곱입니다(수치예보의 과정 분할 = Lie–Trotter/Strang). 3단계 2차에서 physics를 Lie 군 밖의 잔차로 붙였을 때 Lie와 경쟁만 했으므로, physics를 **군 안에** 넣습니다: 칼럼 잠재 상태 위의 복합 군 G = (SO(3) × Vert) ⋉ Fib, 즉 수평 이송(SO(3), Killing 사영) × 수직 이동(Vert = 쉘 축 평행이동, 상승·하강) ⋉ 물리 가족(Fib = 아핀 생성자: 복사 편향, 쉘 라플라시안 모드 위의 교환 가능한 수직 혼합, 보존형 지표 교환, 게이트 응결). 반직접곱은 "이송된(라그랑주) 좌표계에서 물리를 적용한다"는 뜻입니다. 진단량(정역학·지균 잔차, N², 포화 결손, 발산·와도, 지표 수지, TISR 위상)을 GNN 입력으로 주고, critic(해석적 진단 + 𝔤 위의 Lie–Fisher 판별)이 현실 정합성을 판정합니다. 이론 참조: Li et al., *Lie Group Machine Learning* (De Gruyter 2019). 설계 문서(한국어): https://claude.ai/artifact/7R6BJ2z27FC5LWu5m3SG18

**구현 (`geometry/composite_group.py`, `eval/physics_diag.py`, `models/pyramid_transition.py`, `models/critic.py`, `eval/stage5.py`):**
- 복합 군: Vert 이동(경계 고정, tanh 상한), Fib 생성자와 정확한 아핀 흐름 Z(dt) = e^{dt A} Z + φ₁(dt A) dt b(혼합 가족은 교환 가능 → 닫힌 아핀 부분대수, 칼럼 합 보존), Strang/Trotter 분할, Cartan 분해 ω = ω_𝔨 + ω_𝔭, Karcher 평균·군 가우시안 불변성 통계.
- 전이: 피라미드 전이의 같은 특징에서 칼럼별 수직 이동 w와 가족별 계수(복사·혼합·지표·응결, 학습 게이트)를 내고, 한 스텝을 exp(½F)·exp(w∂_η)·exp(ω)·exp(½F)로 합성합니다. 이동 헤드는 0 초기화, 가족마다 이득이 0에서 시작(혼합·응결은 straight-through 사영으로 비음수)하므로 G1은 P와 같은 모델에서 출발합니다. 생성원 크기는 L_fib로 벌점.
- 진단 입력 80채널: 층 쌍별 정역학 두께 오차와 N², 층별 지균 불균형 비(적도 ±10° 제외)·1 − q/q_s·발산·와도, 지표 지균 비·10 m 발산·와도, t2m − T₁₀₀₀. 실제 WB2 2018에서 정역학 오차 중앙값 ~1e-3, N² ~1e-4 (성층권 4e-4), 지균 비 0.1(상층)–0.25(1000 hPa)로 물리적으로 맞는 값입니다. 0.25° 격자의 극 행도 처리합니다.
- critic: 진단 critic은 관측 프레임의 EMA 통계 대비 위도 행별 동서 평균·로그 분산을 비교합니다(흐린 예측이 나쁜 점수를 받도록 분산 항 포함; 실제 2018 상태 1.29, 동서 평활 1.66, 잡음 10.6). Lie–Fisher critic은 관측 바람의 Killing 투영(같은 피라미드 사영, 스텝당 rad)과 모델 생성원 사이의 Fisher 판별(쉘·패치 레벨별, Cartan 좌표, 합동 공분산)입니다. G3는 L_phys·L_fisher를 첫 200 스텝에 걸쳐 켭니다. 앙상블 멤버 가중은 멤버 간 표준화한 점수의 softmax.
- 평가 `scripts/eval_stage5.py` + `report_stage5.py`: 쉘별 가족 활동과 불안정(N² < 0) 칼럼 조건부 혼합, 가족·이동 knock-out, TISR = 밤 반사실, Cartan 스핀/이송 에너지, critic 가중 앙상블 CRPS·spread/skill·critic–오차 순위 상관, 2018 대 2020 군 통계. P1(72h RMSE)은 `compare_graphcast.py`.
- 테스트 25개 추가(전체 83개).

**팔 (`configs/wb2_g1.yaml`·`wb2_g2.yaml`·`wb2_g3.yaml`):** G0 = 4단계 P(플래그 끔, 기존 체크포인트 그대로 로드), G1 = +Vert·Fib, G2 = +진단 입력, G3 = +critic. 같은 데이터·단계·스텝 예산. 예측 P1–P5와 판정 기준은 설계 문서 §7과 `report_stage5.py` 머리말.

### 5.1 G1 결과와 원인 분석 (`stage5_causal_lie/causes/`)

- TISR = 밤 반사실: 복사가 강한 곳 집중도 2.6배(기준 ≥ 2 통과), 효과 크기 5.6e-4(기준 3.7e-2 미달), 복원 t2m 변화 −0.003.
- 학습 없이 보정한 critic으로 멤버를 가중하면 CRPS가 오히려 나빠지고(72h z500 511 vs 496) critic 점수와 실제 오차의 순위 상관은 0.009입니다.

**원인 분석 도구 (`eval/causes.py`):** 예보 오차를 정확히 둘로 나눕니다. 자동부호화기 바닥 rec = D(E(X_k)) − X_k(어떤 전이로도 지울 수 없는 몫)와 잠재 동역학 오차 dyn = D(Z_k) − D(E(X_k)). 같은 초기 상태·같은 denoiser 잡음으로 일부를 끈 롤아웃과 초기 시각별로 짝지어 비교하고 90% bootstrap 구간을 냅니다. 31개 초기 시각, 단일 멤버, 재학습 없음.

1. **짧은 리드 손해는 자동부호화기 때문입니다.** 6h z500 바닥이 P 361, S 254(+42%)로 P의 6h 손해(+35%)와 같은 크기이고, 6h 동역학 오차는 비슷합니다(220 vs 193). P의 repr 단계 복원 손실은 이봉 분포입니다(skip이 있으면 0.96, skip이 끊긴 표본은 2.1, S는 0.55). skip dropout(0.5)과 V-Net 자체 용량이 모두 후보라, skip dropout을 끈 **P−nodrop**을 원인 ablation으로 학습했습니다.

   **결과: 원인은 skip dropout입니다.** P−nodrop의 6h z500 바닥은 271로 S(254)에 붙었고 P(361)와의 차이의 84%가 사라졌습니다(83개 변수 평균 94%, 중앙값 92%). 변수 평균 바닥 비율도 0.82 / 0.42 / 0.20으로 S와 같습니다. 그래서 P−nodrop은 6h에서 P보다 크게 좋고(z500 −21.5%, q700 −22.1%, mslp −20.4%), 24h에서는 S와 같거나 낫습니다(t850 −4.0%, t2m −2.9%, mslp −1.7%, z500 +1.2%). 남은 V-Net 용량 몫은 z500 6h 바닥 기준 +7%입니다.

   **그러나 72h에서는 P−nodrop이 S보다 나쁩니다**(z500 +8.8%, q700 +5.8%, mslp +4.9%, t2m +3.1%; t850만 −1.4%). 바닥은 S와 같으므로 차이는 잠재 동역학입니다(z500 dyn +7.2%). 피라미드 팔 사이에서는 skip에 덜 기댈수록 72h 동역학 오차가 작습니다(P−nodrop 872 > P 865 > P−skip 749). skip dropout은 자동부호화기를 흐리게 만든 대신 거친 레벨로 정보를 보내 긴 리드 포화를 늦추는 정규화로도 작용한 것으로 해석합니다(검증 안 된 해석). 곧 피라미드 전이 자체는 아직 긴 리드에서 S의 단일 레벨 전이보다 낫지 않습니다.

2. **긴 리드 오차는 잠재 동역학이 주원인입니다**(72h 바닥 비율 0.1–0.3). P−skip의 72–120h 이득은 동역학 오차가 작아서인데(749 vs 814), 이는 상태가 거의 움직이지 않는 매끄러운 모델이라서입니다(4단계 4.1절).
3. **DIAMOND denoiser는 평균 기술을 더하지 않습니다.** 끄면 S·P·G1 모두 거의 모든 변수·리드에서 단일 멤버 RMSE가 2–12% 좋아지고(예외: G1 72h t850 +1.3%), P의 72h z500에서는 4멤버 앙상블 평균(단일 멤버 대비 −3.2%)보다도 낫습니다(−6.3%). 지금의 잔차는 잡음으로 퍼짐만 늘리고, 그래도 spread/skill은 0.25–0.4로 부족합니다.
4. **G1의 복합 군은 물리 가족이 아니라 보정항으로 쓰입니다.** 끄면 t850이 21%까지 나빠지지만(전이와 함께 적응), 혼합은 음의 이득(반확산, 곧 선명화)을 원해 꺼졌고 응결·수직 이동은 거의 0입니다. 흐린 자동부호화기를 보정하려는 신호로 해석합니다. 그래서 G1 전체는 P와 비슷합니다.
5. **critic 점수는 아직 오차를 구분하지 못합니다**(순위 상관 0.009). critic으로 학습하는 G3의 전제가 사후 검사에서 성립하지 않습니다.

**방향성:** 측정된 가장 큰 오차원은 짧은 리드의 자동부호화기 바닥과 긴 리드의 잠재 동역학·denoiser 잡음이고, 5단계의 물리 생성자는 어느 쪽도 직접 겨냥하지 않습니다. 추천 순서: (1) P−nodrop으로 자동부호화기 원인 확인 → **완료, skip dropout이 원인**이므로 이후 새 팔(6단계 H0–H2)은 skip dropout 0을 바탕으로 합니다, (2) 진단량 입력 G2는 설계대로 실행(아직 검증 안 된 유일한 5단계 요소; G1과 비교하려고 P 바탕을 유지하므로 G 팔은 자동부호화기 바닥을 그대로 안고 있고, G2 대 G1 차이만 해석합니다), (3) G3는 critic 점수가 오차를 추적할 때까지 보류, (4) 다음 후보는 결정론적 Lie 이송을 평균으로 쓰고 denoiser는 보정된 퍼짐만 내는 확률 단계입니다.

## 6단계 — 쉘 그래프 결합 (`stage6_shell_graph/`)

**가설 (감자, 10/31 13:18):** 쉘 사이 사슬 결합을 놓고 그래프 단위로 연결합니다. 회전의 사슬(g_s = g_{s−1}·exp δ_s)은 1단계 ablation 뒤로 이미 꺼져 있었고, 사슬이 남아 있던 곳은 모든 GNN 층의 수직 혼합(바로 위아래 쉘만 보는 `VerticalShellMixer`)과 5단계의 쉘 축 라플라시안이었습니다. 5개 쉘(지표·경계층·하부 대류권·상부 대류권·성층권)을 완전 그래프로 이으면 심층 대류(경계층 ↔ 상부 대류권), 지표 복사·플럭스처럼 이웃을 건너뛰는 연직 결합을 직접 표현할 수 있고, 5단계 G1에서 사슬 혼합이 꺼진 것도 국소 사슬 구조가 맞지 않았기 때문인지 가릴 수 있습니다.

**구현 (`models/layers.py`, `models/pyramid_transition.py`, `eval/causes.py`):**
- `ShellGraphMixer` (`model.gnn.vertical: graph`): 모든 쉘 쌍의 메시지 전달. 가중치 a_ss' = softmax(B_ss' + ⟨q(h_s), k(h_s')⟩/√d), B는 사슬 이웃을 선호하도록 초기화(비사슬 간선 몫 0.11)하고 q는 0에서 시작합니다. 받는 쉘은 다른 쉘 상태의 가중 평균과 쉘 쌍 임베딩의 가중 평균(어디서 온 정보인지)을 받습니다. 같은 노드의 쉘은 접평면을 공유하므로 벡터 이송이 필요 없고 SO(3) 등변성이 유지됩니다. 인코더·디코더·V-Net·전이·denoiser의 사슬 혼합기 13개를 모두 바꿉니다(파라미터 +9%).
- 생성원 그래프 결합 (`model.lie.shell_coupling: graph`, 피라미드 전이): 모든 패치·레벨에서 ω_s = δ_s + Σ_{s'≠s} A_ss' δ_s'. A = 0이면 독립 쉘, 엄격 하삼각 1이면 1단계 사슬의 1차(BCH) 근사입니다(테스트로 확인). 관측 바람의 생성원(5단계 critic)에는 적용하지 않습니다.
- 원인 분석: `nonlocal`(혼합기를 사슬 간선으로 제한), `shell_graph`(A = 0) knock-out, 학습된 그래프(사전 B, 상태 의존 평균 가중치, 비사슬 몫, A) 요약을 `eval_causes.py`·`report_causes.py`에 추가했습니다.
- 물리 수준의 그래프 라플라시안 혼합(L = D − W, W ≥ 0)은 H 팔에 복합 군이 없어 보류했습니다.

**팔:** H0 = P−nodrop(사슬 혼합, 독립 쉘; skip dropout을 끈 4단계 P), H1 = H0 + 쉘 그래프 혼합기(`configs/wb2_h1.yaml`), H2 = H1 + 생성원 그래프 결합(`configs/wb2_h2.yaml`). 같은 데이터·단계·스텝 예산.

**예측(사전 등록):** (1) H1은 H0보다 72h 단일 멤버 RMSE가 연직 교환 변수(q700, t850, t2m)에서 2% 이상 낮고 90% 구간이 0을 포함하지 않는다. (2) 비국소 간선이 쓰인다: 상태 의존 비사슬 몫이 사전(0.11)보다 크고, `nonlocal` knock-out이 RMSE를 올린다. (3) 가장 큰 비사슬 가중치는 경계층·지표와 상부 대류권 사이(심층 대류)에 있다. (4) H2의 A는 0이 아니고 `shell_graph` knock-out이 RMSE를 올린다; A가 사슬(하삼각 양수)에 가까운지, 순압 결합(모두 양수)에 가까운지 기록한다.

## 7단계 — 예측 게임과 GNN feature 제어 (`stage7_prediction_game/`)

**가설 (감자, 10/31 14:06):** Lie 구조에 매몰되지 말고, 세계 모델이 물리를 이해해 미래를 예측하게 만드는 데 집중합니다. 예측을 하나의 게임으로 보고(Ha & Schmidhuber 2018 World Models, Freeman·Metz·Ha 2019 observational dropout), (1) 물리 예측 구조를 먼저 학습해 고정하고, (2) 마스킹된 데이터를 예측하는 게임에서 GNN feature를 조절하는 제어만 보상으로 학습한 뒤, (3) 전체 모델을 시험합니다. 설계 문서: [7단계 설계: 예측 게임과 GNN feature 제어](https://claude.ai/artifact/H8az4WzNqJvUuvWYYGz1LU).

**구현 (`models/feature_control.py`, `train/prediction_game.py`):**
- 제어기(`FeatureController`, 8.9k 파라미터): 쉘 × 12개 패치마다 잠재 스칼라·벡터 크기 평균, 디코딩한 현재 상태의 물리 진단량(5단계 모듈의 7개 가족을 쉘별 평균), 마스크 비율, 쉘·패치 정체를 보고, 잠재 스칼라에 저차수 FiLM h ← h + 0.1·(h·Uγ + Uβ)(r = 4, U 고정 직교 기저)를 겁니다. 스칼라만 바꾸므로 SO(3) 등변성은 유지되고, 마지막 층이 0에서 시작해 학습 전에는 고정 모델과 똑같습니다. 세계 모델의 하위 모듈로 등록하지 않아 체크포인트는 바뀌지 않습니다(`controlled(model, ctrl)`).
- 게임(순차형, 감자 10/31 15:09): 한 판은 x_t → x_{t+6h} → … → x_{t+36h}의 6스텝 시퀀스입니다. 판마다 변수 하나(모든 층) 또는 표면 묶음, 쉘 하나, 지구 면적 25%의 원형 지역 중 하나를 가리고 기후값(0)으로 채웁니다. 시퀀스 중간 각 스텝에서 확률 0.5로 실제 관측(가려진 채)을 다시 보여 주고, 나머지 스텝은 모델이 자기 예측으로 이어 갑니다(observational dropout). 스텝 보상 r_k = −[0.5·가려진 점의 MSE + 0.5·전체 MSE](GraphCast 가중). 세계 모델은 denoiser를 끈 결정론 모드입니다.
- 학습: `rl` = 상태마다 행동 시퀀스 4개(가우스 정책, σ = 0.5). 스텝 k의 행동은 그 뒤 보상의 합(reward-to-go Σ_{j≥k} r_j)을 그룹 안에서 정규화한 이점으로 평가합니다(2단계 GRPO 방식의 순차 확장); `grad` = 같은 제어기를 고정 모델을 통한 정확한 기울기로 학습(대조군). 100회 갱신(6스텝 × 100 = 이전 4스텝 × 150과 같은 계산량), 같은 창·같은 마스크·재관측 순서, 10회마다 이어 하기 저장. 시험 게임도 같은 규칙(초기 시각마다 고정된 마스크와 재관측 순서)입니다.
- 원인 분석: `eval_causes.py --controller --deterministic`에 `no_control`(고정 모델), `random_control`(같은 행동을 섞인 쉘·패치 위치에), `no_diag`(진단량 입력 0) knock-out을 추가했고, `eval_game.py`는 같은 knock-out을 마스킹 게임에서 잽니다.

**팔:** 기본 모델 = P−nodrop(2015–17 학습, 고정). C0 = 행동 0, C1 = RL 제어기, C1-grad = 기울기 대조군, C1-open = 상태를 보지 않는 상수 행동, C1-random·C1-nodiag = C1의 평가 시 knock-out. 게임 학습 2018–19, 시험 2020(31개 초기 시각). 2차 후보: C1-nomask(마스킹 없는 게임), 입력 feature 게이트 행동.

**예측(사전 등록):** Q1 C1이 2020 마스킹 게임에서 가려진 변수의 24h 오차를 C0보다 3% 이상 줄이고(36h는 기록) 90% 구간이 0을 포함하지 않는다. Q2 C1의 이득이 C1-random·C1-open보다 크다. Q3 마스킹 없는 보통 예보에서 6–72h 어느 리드에서도 0.5% 넘게 나빠지지 않는다. Q4 C1-nodiag가 이득의 절반 이상을 잃는다. Q5(기록) C1 대 C1-grad. Q1과 Q2가 모두 성립하면 지지로 판정합니다.

## 8단계 — 동역학적 대기의 위상 (`stage8_topology/`)

**가설 (감자, 10/31 15:04):** 세계 모델의 예측에는 정역학(상태가 어디에 있고 어디와 이어져 있는가)과 동역학(어떻게 움직이는가)이 모두 필요합니다. NEO 쪽이 인과적 동역학을 맡는다면 위상은 약합니다. 그래서 물리적 전이 비용 C_T(X,Y) = inf ∫ ½‖a‖²_G dt (Ẋ = F + Ba)로 근방을 정의해 동역학적 대기의 위상을 배웁니다. 첨부 논문: Learning Commute-Time-Preserving World Models for Planning (arXiv 2610.01373). 설계 문서: [8단계 설계: 동역학적 위상(전이 비용) 학습](https://claude.ai/artifact/Y8G5FeKMbF77Vc8voYJ9B5).

**정리:**
- 시간을 포함한 비용 C(X,Y) = inf_T [λT + C_T(X,Y)]는 경로 잇기로 삼각부등식을 만족하는 준거리이므로 전방 비용 공이 기저가 됩니다.
- 국소 제어 가능하면 위상은 보통 위상과 같고, 바뀌는 것은 기하(비등방 공)입니다. 새 위상은 왕복 비용이 작은 상태들의 레짐에서만 생깁니다.
- 왕복 비용의 확률적 대응이 커뮤트 타임이고(Freidlin–Wentzell, Eyring–Kramers), CTWM 손실 ‖φ(s′) − φ(s) − T(φ(s), a)‖² + β‖T‖² − (γ/2) log det Cov φ의 최적해는 거리² ∝ 커뮤트 타임, 방향별 분산 ∝ 1/λ인 Laplacian 임베딩입니다(가역 동역학 가정).

**1차 구현 (`models/commute_time.py`, `eval/topology.py`, `scripts/eval_topology.py`):**
- 상태: 고정 P−nodrop 인코더의 latent를 쉘 × 12 패치로 평균한 회전 불변량(스칼라 평균, 벡터 크기), 2015–17 조화 기후값을 뺀 편차.
- 행동: 다음 시각의 패치별 대기 상단 입사 태양복사와 계절 위상(강제가 만드는 변화는 T가 설명).
- 머리: 전역 ψ(16차원) 또는 패치 ψ(8차원, 가중치 공유). 2015–17의 6h 전이로 학습, 2018로 시험.
- T1: k-means 64개 군집의 Markov 상태 모형에서 계산한 커뮤트 타임과 군집 중심 거리의 Spearman(latent·에너지 두 분할), 시간 간격에 따른 거리 증가.
- T2: 기하 = 주방향 분산과 Laplacian 고유값의 log-log 기울기(이론 −1). 위상 = 같은 공분산의 가우스 구름보다 오래 사는 H0 성분 수, k-means 레짐 체류 시간, 북대서양·북태평양 패치.
- T3: 유사 사례 예보(가까운 10개의 24·72·120h 뒤 평균)의 z500·t850·t2m RMSE, 블로킹·제트 위도 레짐별; ψ의 국소 속도·희귀도와 고정 모델 72h 오차의 상관.

**팔:** ψ-CT(본 가설), ψ-iso(등방 정규화, 1/λ 척도 제거), ψ-shuffle(무작위 쌍, 음성 대조), raw z(고정 latent), 에너지 노름(건조 전에너지). 원인 분석: β ∈ {0, 0.1, 1}, 차원 8/16/32, 강제 행동 끔, 패치별 머리.

**예측(사전 등록):** P1 ψ-CT의 커뮤트 타임 Spearman이 raw z·에너지 노름보다 0.1 이상 높다(구간이 0 제외), ψ-shuffle은 0.2 미만. P2 ψ-CT 분산 스펙트럼 기울기가 −1.3 ~ −0.7, ψ-iso는 범위 밖. P3(기록) 전역에서는 새 위상 없음, 북대서양·북태평양 패치에서 H0 성분·체류 시간이 raw z보다 30% 이상이면 레짐을 위상적 내용으로 기록. P4 ψ-CT 유사 사례 72h z500 RMSE가 raw z보다 3% 이상 낮고, ψ 속도와 고정 모델 72h 오차의 Spearman ≥ 0.3. P1과 P4가 모두 성립하면 지지, 2차(인코더에 CTWM 보조 손실 + 방향을 담는 준거리 머리)로 진행합니다.

**원인 분석**
1. **커뮤트 타임 목적이 원인이 아닙니다.** T1에서 ψ-iso(1/λ 척도 제거), 강제 행동 끔(0.49), β 0·0.1·1(0.50)이 모두 ψ-CT와 같습니다. 무작위 쌍(ψ-shuffle)만 무너집니다(−0.08). 그래서 상관을 만드는 것은 "시간상 이웃"이라는 정보이고, 이 정보는 raw z에도 이미 있습니다(시간 간격에 따른 거리 증가 ρ 0.89–0.93이 모든 표현에서 같음).
2. **16차원 병목이 예측 정보를 버립니다.** 유사 사례 오차가 차원과 함께 줄어듭니다(72h z500: 8차원 1270, 16차원 1190, 32차원 1180). ψ는 느린 방향에 분산을 몰아주므로(기울기 −2) 빠른 종관 변동의 차이를 잃습니다.
3. **유사 사례 시험 자체가 약합니다.** 3년 라이브러리에는 진짜 유사 사례가 없습니다. raw z 유사 사례 예보도 24h부터 기후값보다 나쁘고(z500 1020 대 약 780), 리드에 따라 거의 늘지 않습니다. 곧 T3는 예측 동역학이 아니라 "가까운 상태를 고르는 정밀도"를 잽니다.
4. **대칭 가정이 방향을 버립니다.** 커뮤트 타임은 왕복(대칭) 양이지만 대기 전이는 비가역이라 비용이 준거리입니다. 설계 때 2차에 방향 머리를 둔 이유이며, 1차의 커뮤트 타임은 이 정보를 원리적으로 담을 수 없습니다.
5. **레짐은 섬이 아니라 밀도가 높은 곳입니다.** 어느 표현에서도 분리된 성분이 없다는 것은 블로킹·제트 레짐을 확률 밀도의 모드로 보는 문헌과 맞습니다.

**방향성**
- **진짜 전이 비용을 직접 계산합니다.** 9단계 물리 모델에서는 N3 제어기의 행동이 바로 Ẋ = F + Ba의 a입니다. 그래서 두 상태 사이 최소 제어 비용 inf ∫ ½‖a‖²를 미분 가능한 코어를 통한 기울기 최적화로 구할 수 있습니다(6–24h). 커뮤트 타임이라는 대리 대신 감자의 정의 그대로 T1–T3를 다시 잴 수 있고, N1 학습 뒤 가능합니다.
- **실용적 수확:** 에너지 노름 속도(ρ 0.45)와 라이브러리 희귀도(에너지 0.52, raw z 0.42)가 세계 모델의 72h 오차를 미리 알려 줍니다. 흐름에 따라 달라지는 불확실성 지표로 바로 쓸 수 있습니다(앙상블 퍼짐 보정, 9단계 평가의 오차 예측기).
- 레짐 위상을 다시 볼 때는 H0 성분 대신 밀도 기반(모드) 분석을 씁니다.

## 9단계 — 물리 중심 세계 모델 (`stage9_physics/`)

**가설 (감자, 10/31 16:36):** 추상적인 Lie 구조에 매몰되지 말고, 세계 모델의 이점인 "물리의 이해와 그에 따른 추론"을 위해 physics를 메인 학습 구조로 삼아 기후 예측을 합니다. 구조 A(방정식 코어 + 신경망 물리)를 골랐습니다(16:51). 강화 부분은 메인 구조를 바꾸지 않고 Ha & Schmidhuber 2018처럼 고정한 세계 모델 위에 작은 제어기를 둡니다(16:56). 설계 문서: [9단계 설계: 물리 중심 세계 모델](https://claude.ai/artifact/CsnpM54EbtjvzPZXTdPpzt).

**구현 (`geometry/spectral.py`, `models/primitive_core.py`, `models/physics_world_model.py`, `models/tendency_control.py`, `train/physics_game.py`):**
- 코어: 기압 좌표 원시방정식의 와도·발산 형식, 구면 조화 T31(96×48 Gaussian 격자, 자료 격자 64×32는 위도별 가중 최소제곱으로 분석). ω는 연속 방정식, Φ는 정역학 관계에서 진단하고, 1000 hPa 지오퍼텐셜은 칼럼 질량 수렴으로 움직입니다. 중력파는 반암시적 IMEX SIL3(Whitaker & Kar 2013), Δt 30분, ∇⁸ 확산(절단 파수에서 3시간), 경계층 Rayleigh 마찰(Held–Suarez, 최하층 1일). 초기 시각의 관측−진단 차이(정역학 잔차 등)는 모든 리드에 더합니다.
- 칼럼 물리(N1): 한 칼럼을 입력받아 가열 Q, 수분 원천 S, 운동량 F, 지표 지오퍼텐셜 경향을 내는 MLP(256×3)를 매시간 부릅니다. 수지 제약: 강수 = relu(증발 − ∫S dp/g), F는 칼럼 평균 0 + 최하 3층 지표 마찰. 지표 머리가 t2m·mslp·u10·v10을 진단합니다. 마지막 층이 0에서 시작하므로 학습 전 N1은 N0와 같습니다. 6시간 스텝마다 gradient checkpoint를 두고 1→2→4스텝 롤아웃으로 학습합니다.
- 제어기(N3): 고정한 N1 위에서 7단계와 같은 마스킹 게임을 합니다. 행동은 6시간마다 온도·와도·습도(4개 층 묶음)와 1000 hPa 지오퍼텐셜의 n ≤ 4 구면 조화 성분을 미는 것(325차원)이고, 한 단위는 그 층 6시간 변화 표준편차의 0.2배입니다. 비용 ½‖a‖²는 8단계 전이 비용 Ẋ = F + Ba의 a입니다.
- 기준선: 재관측 때 예측을 유지하고 관측된 점만 진값 쪽으로 당기는 고전적 nudging(직접 삽입, 절반 세기)을 7단계·9단계 게임 평가에 넣었고, nudging 규칙 위에서 학습하는 팔(C1nudge, n3nudge)도 둡니다.
- 확장 설정: 칼럼망 폭 ×2·×4, T42(1.5°), T119(1°, 클러스터 Lustre 시간별 ERA5).

**팔:** N0 = 코어만(학습 없음), N1 = 코어 + 칼럼 물리(주 팔, 2015–17 학습), N3 = N1 고정 + 제어기(rl / grad / open / nudge, 게임 2018–19, 시험 2020). 기준: S(1단계), P−nodrop, 지속, 기후값, GraphCast.

**예측(사전 등록):** Q1 N0의 72h z500 RMSE ≤ S. Q2 N1이 S보다 30% 이상 낮고 P−nodrop보다 낮다. Q3 1년 자유 적분의 표류 < 1 K/년, < 1 hPa/년. Q4 학습된 Q·S와 ERA5 Q1·Q2의 패턴 상관 ≥ 0.5. Q5 해양 skt +2 K에 TCWV +10–16%. Q6 N3가 행동 0보다 가려진 오차를 3% 이상 줄이고, 제어 에너지가 경계층·습윤 과정에 모인다. Q7 칼럼망 폭 ×2·×4의 이득 < 5%. Q2와 Q3가 성립하면 지지로 판정합니다.

**질문 (감자, 10/31 20:49, 20:54):** 물리 작용의 인과를 추론하되, 기후 모델의 결합 그림처럼 인과가 복합적이라는 점을 반영해야 합니다. 그림의 다섯 마디는 열역학 방정식, 운동 방정식, 복사 전달, 물 질량 보존, 지표 열수지(해양/육지)입니다. 화살표는 다음과 같습니다.
- 이류: 운동→열역학, 운동→물
- 밀도: 열역학→운동
- 잠열: 물→열역학
- 수분: 물→복사
- 가열·냉각: 복사→열역학
- 열에너지, 눈·얼음: 지표↔복사
- 강수·증발: 지표↔물

감자는 21:11에 이 그림의 PDE 구조를 근사한 식도 보냈습니다. 식에서 블록 사이를 오가는 결합 변수는 다음과 같습니다.
- T′: 열역학→운동량. 기압경도의 RT′∇log p_s 항입니다.
- u, σ̇: 운동량→열역학, 운동량→수분 이송.
- T: 열역학→정역학 균형·질량 보존.
- Φ, p_s: 정역학→운동량.
- T_v: 수분→정역학.

학습된 물리 Ψ_θ(X, ξ)는 모든 블록에 더해지고, 시간 적분은 SIL3(IMEX)입니다. N1의 코어는 이 구조를 기압 좌표로 쓴 것이라 σ̇ 대신 ω, p_s 대신 1000 hPa의 Φ_b를 씁니다. 식과 다른 점은 세 가지입니다.
- 응결수(q_ci, q_cl)는 WB2 자료에 없어서 T_v에 q만 들어갑니다.
- Ψ_θ는 결정론적이라 잡음 ξ가 없습니다. 10단계의 기억 커널이 Mori–Zwanzig의 기억 항을 맡습니다.
- T′는 기압 좌표에서 Φ = Φ_b + ∫R T_v d ln p를 거쳐서만 운동량에 들어갑니다. 그래서 식의 "T → 정역학"과 "T′ → 운동량"은 N1에서 한 화살표입니다.

**방법 (`eval/physics_causes.py`, `scripts/eval_physics_causes.py`, `scripts/report_physics_causes.py`):** 재학습 없이 평가할 때 화살표마다 하나씩 끊습니다. 코어의 결합 변수 차단은 `primitive_core.CUTS`가 맡고, 명시·선형·암시 부분을 똑같이 바꿔 IMEX 분할이 일관되게 유지됩니다.

| 화살표 (그림 / 식) | N1에서 끊는 방법 |
|---|---|
| 운동→열역학 (이류 / u, σ̇) | 온도의 수평·연직 이류만 끄기 (`core.cuts=[temp_advection]`). 단열 항 κTω/p는 따로 끔 |

그 밖에 코어 항(코리올리, 연직 이송, 수평 이송 전체), 마찰, 초기 잔차 이월, 칼럼 출력별(가열, 수분 원천, 운동량, 지표 기압) 끄기도 같이 돌립니다.

그림에 고리가 있으므로 단일 끄기만으로는 부족합니다. 복합성은 세 가지로 봅니다.
1. **쌍 개입**으로 고리의 비가법성을 잽니다. 상태 공간에서 η = |D_AB − D_A − D_B| / (|D_A| + |D_B|)이고, D_X는 개입 X의 예보에서 원래 예보를 뺀 것입니다. 경로가 독립이면 η = 0입니다. 매개는 ρ(A | B) = |예보_AB − 예보_B| / |D_A|로 잽니다. B가 A의 효과를 전달하면 ρ → 0입니다.
   - 쌍: 열역학↔운동(온도 이류 × T′ 결합 10% 약화), 수분→정역학→운동→수분 고리(수분 이류 × T_v 끄기), 잠열 고리(수분 이류 × q→가열), 응결 고리(T→수분 원천 × q→가열), 태양 × 가열(매개), 태양 × q→가열(수분이 태양 가열을 조절), 태양 × 해양 칼럼.
2. **전파 행렬**: 각 개입에 대한 반응 |D_X|를 변수 묶음별(열역학: T·t2m, 운동: 바람·z·mslp, 물: q·강수)로 6–72h 매 리드마다 기록해, 개입이 어느 마디에 언제 닿는지를 화살표 순서와 비교합니다.
3. **불변성**: 같은 날짜(1월 1일부터 48일 간격 8개, N0 knock-out과 같음)로 2018년과 2020년에 돌리고, N0와 부호를 비교합니다.

기술 점수는 채널 평균 정규화 MSE와 대표 변수 RMSE의 원래 모델 대비 변화(부트스트랩 95%)입니다. 발산한 실행은 세고 그 리드부터 짝에서 뺍니다. 모든 개입에 대해 낮/밤 지점의 t2m 반응과, 시작 이후 받은 햇빛 에너지와의 상관도 기록합니다.

- 육지에서 특히 그렇습니다. 그림의 지표 열수지 마디(땅/바다의 열 저장)가 N1에 없어서, 칼럼이 육지 위 일변화와 지표 가열을 대기 가열만으로 흉내 냅니다. 모두 바다로 바꾸면 z500이 나아지는 것이 그 증거입니다.
- T_v 결합은 이 해상도에서 거의 쓰이지 않습니다.

**방향성**
1. 칼럼 에너지 수지:
   - 제약: ∫Q dp/g = 복사(TISR와 OLR 근사) + L·P + 감열.
   - 이유: z500 편향의 원인을 직접 겨눕니다.
   - 판정: 같은 개입에서 "가열 끔"의 z500 부호가 +로 돌아오는지 봅니다.
2. 지표 상자:
   - 내용: 지표 열 저장과 물 저장 상태 변수를 칼럼에 하나씩 추가합니다(slab와 bucket). 그림의 지표 마디와 지표↔물 화살표를 채웁니다.
   - 비교: 10단계 기억 커널이 이 느린 저장을 스스로 배우는지와 비교합니다(D-memctrl의 τ 지도).
3. 위 둘은 구조의 변경입니다. 같은 시간에 도는 확장성 시험(§9.3)이 "키우면 된다"를 보이지 못하면, 이것이 다음 단계의 근거가 됩니다.

### 9.3 확장성: N1은 크기에 막혀 있는가 (`stage9_physics/scaling.md`)

## 10단계 — 적응형 기억 커널과 DreamerV3식 유동 학습 (`stage10_memory/`)

**가설 (감자, 10/31 18:32–19:12):** 9단계 N3처럼 세계 모델을 얼리고 기억 없는 제어기만 학습하는 것은 World Models를 잘못 옮긴 것입니다. DreamerV3처럼 세계 모델이 계속 배우고(유동성), 에이전트가 기억을 가져야 합니다. 핵심은 "행위자 입력에 마스크된 관측 → 그 관측을 받는 기억의 물리 → 적응형 기억을 통한 미래 예측"입니다. 설계 문서: [10단계 설계: 적응형 기억 커널과 DreamerV3식 유동 학습](https://claude.ai/artifact/KqNAQg5dARnZhdAkwqfUzj).

**구현 (`models/memory_kernel.py`, `models/physics_world_model.py`, `train/dreamer_game.py`, `scripts/train_dreamer.py`, `scripts/eval_dreamer.py`, `configs/dreamer_wb2.yaml`):**
- 기억: Mori–Zwanzig 기억 적분 ∫K(τ, X)X(t−τ)dτ 를 지수함수 합으로 두면 칼럼별 선형 점화식 m ← a⊙m + (1−a)⊙b(x), a = e^{−Δt/τ(x)} 가 됩니다(K = 16채널, τ 초기값 3시간–10일). 매시간 칼럼 물리 호출 때 갱신하고, 구면조화 확산 e^{−κ n(n+1)}(κ 학습)으로 이웃에 퍼지며, 칼럼 경향에 더해집니다. 적응형 = τ(x)와 b(x)가 칼럼 상태의 함수(선택적 상태공간), 고정 = τ 상수와 선형 b·G.
- 관측: 첫 시점의 마스크된 스냅샷과 이후 재관측마다 기억이 혁신을 흡수합니다(m += G(예측, 혁신, 관측 여부, m)). 숨은 점은 평균값 대신 예측 + R(m)으로 채웁니다. 기억의 출력층은 모두 0에서 시작하므로 학습 전 모델은 N1 + nudging(α=1)과 정확히 같습니다(테스트로 확인).
- 학습(한 반복): ① 세계 모델: 2018–19 마스크 시퀀스 2개를 현재 행위자와 함께 36시간 굴려 GraphCast 가중 오차로 칼럼 물리(학습률 1e-4)와 기억·G·R(1e-3)을 갱신합니다. ② 행위자·비평가: 마스크된 한 시점에서 기억 0으로 시작해 행동 4개로 36시간을 굴리고, 그동안 ERA5 관측이 확률 0.5로 들어옵니다. 보상은 정확한 음의 오차, λ-수익(γ=1, λ=0.95), 수익 정규화 S = EMA(P95−P5), REINFORCE, EMA 비평가. 행위자는 9단계 제어기에 최근 마스크 관측과 기억의 저차 계수를 더 읽습니다. D-blind는 DreamerV3 그대로(사후 상태에서 관측 없이 상상, 보상 머리)입니다.
- 폭주: 스모크에서 학습 중인 N1(200/1000)이 영역 마스크 상태에서 36시간 안에 폭주했습니다(N0는 안정). 평균값으로 채운 숨은 영역이 칼럼 물리에 낯선 입력이기 때문으로 봅니다. 학습은 폭주 직전에서 끊고(배치 안의 NaN 하나가 기울기를 망치므로 샘플별로 굴림), 점수는 상한 10으로 매기고 폭주 횟수를 따로 보고합니다.

**제어를 통한 적응 기억 (감자, 19:52):** "world model은 메인 물리 기억의 예측, control을 통한 adaptive 즉 적응 기억". 물리 기억 = 세계 모델의 가중치(여러 해에서 천천히 배움), 적응 기억 = m(관측을 흡수하고 τ로 얼마나 오래 기억할지 정함)입니다. D-memctrl은 행위자가 물리 상태를 건드리지 않고 기억만 조절합니다: 채널마다 저차 구면조화(n ≤ 2)로 m에 쓰기, 그리고 다음 6시간 동안 ln τ 이동(`control.target: memory`, 행동 288차원). 물리는 기억의 경향 항과 판독을 통해서만 영향을 받습니다.

**학습 단계 (감자, 19:56):** 단계별 = N1(물리 기억, 2015–17 지도학습) → D-noactor(적응 기억, 2018–19 게임, 행위자 없음) → D-frozen / D-frozen-memctrl(모델을 얼리고 강화학습만). 번갈아 = D / D-memctrl(반복마다 세계 모델·기억 갱신과 행위자·비평가 갱신을 번갈아). 두 경로의 비교가 "함께 배우기"의 효과입니다.

**팔:** D(본안), D-blind(관측 없는 상상), D-noactor(행위자 없음), D-markov(기억 없음), D-fixed(고정 커널), D-frozen(D-noactor의 세계 모델을 얼리고 행위자만), D-memctrl(행위자가 기억만 조절), D-frozen-memctrl(D-noactor를 얼리고 기억 조절 행위자만). 기준: N1 + nudging(α=1, 기준점), nudging_half, 7·9단계 게임 규칙. 평가 끄기: 기억, 혁신, 판독, 확산, τ 고정, 행위자. 시험은 2020년 31개 초기 시각 × 마스크 3종(변수·셸·영역), D와 D-markov는 2018–19 15개로 과적합도 봅니다.

**예측(사전 등록):** P1 D가 nudging보다 24시간 숨은 오차 10% 이상 낮음. P2 적응형이 고정 커널보다 3% 이상 좋음. P3 D-markov가 nudging보다 5% 이상 좋고 2018–19와 2020 차이 < 5%. P4 행위자의 추가 이득 < 2%. P5 기억의 이득은 영역 마스크에서 가장 크고 확산을 끄면 절반 이상 사라짐. P6 학습된 τ(x)의 상태 의존성: 채널마다 칸 사이 90/10 백분위 비를 구한 중앙값 ≥ 2 (채널들은 처음부터 3시간–10일로 벌어져 있으므로 채널을 섞은 비는 쓰지 않음).

**2차: 기억을 통한 기후 예측 (감자 19:52, `eval/memory_climate.py`, `scripts/eval_memory_climate.py`):** Mori–Zwanzig로 보면 모델에 없는 느린 변수(해수면 온도, 토양 수분, 해빙)는 대기에 τ가 긴 기억으로 작용하고, 2주 너머의 예측력은 여기서 나옵니다. 2020년 초기 시각 8개마다 10일 동안 6시간마다 (마스크된) 참값을 다시 넣어 기억을 채운 뒤, 관측 없이 4주를 자유 예측하고 주평균을 ERA5 주평균·기후값과 비교합니다(S2S 방식: GraphCast 가중 MSE, 변수별 RMSE·ACC). 마스크는 `none`(스핀업 동안 전부 관측)과 `region`(25% 캡을 끝까지 숨김). 비교: 팔 전체, 행위자 끔, 기억 끔, N1 + nudging(같은 스핀업, 기억 없음). 폭주한 실행은 그 시점부터 기후값으로 채점하고 따로 셉니다. 대상: D, D-memctrl.

**2차 예측(사전 등록):** C1 `none`에서 D의 3–4주 주평균 오차가 N1 + nudging보다 3% 이상 낮음(기억이 느린 정보를 지님). C2 `region`에서 1–2주 숨은 점 오차가 5% 이상 낮음. C3 D-memctrl이 3–4주에서 D보다 낮음(제어가 느린 기억을 돕는다). C4 3–4주에는 어느 변형도 기후값을 넘지 못함(자유 예측의 표류; 넘으면 C1과 함께 강한 증거).

### 10.2 2년의 기억: 느린 채널과 연속 필터 학습 (`stage10_memory/long.md`)

**요청 (감자, 11/01 09:18–09:21):** "기억을 더 채울 수는 없나요? 한 2년 정도의 기억을 채우면?" 결정: 싼 시험과 10.2를 둘 다.

**왜 지금 커널로는 안 되는가:** 10단계 커널의 시간 척도는 `tau_hours: [3, 240]`로 10일이 상한입니다. 채워진 비율은 1 − e^{−T/τ}이므로 가장 긴 채널은 10일 스핀업에 63%, 30일에 95%, 2년에 100%인데 30일과 같습니다. 한 달 넘은 것은 잊는 커널이라 "2년의 기억"은 (1) 년 단위 τ를 가진 채널과 (2) 그것을 쓸 수 있게 하는 학습이 있어야 뜻이 있습니다. 36시간 에피소드에서는 τ = 2년인 채널이 거의 움직이지 않아 배울 신호가 없습니다.

**콜드스타트가 드러낸 것 (09:30):** §10.1의 2020년 콜드스타트에서 D-noactor의 자유 예보가 N1보다 2–3배 나쁘고 120h 전에 발산했습니다. 재관측 확률 0.5의 게임으로 함께 학습한 칼럼이 필터가 되어 자유 예보를 잃은 것으로 보입니다(웜스타트 결과로 확정). 10.2의 학습은 이 문제를 함께 겨냥합니다.

**설계 (`models/memory_kernel.py` 느린 채널, `train/memory_filter.py`, `scripts/train_memory_filter.py`, `configs/memory_filter_wb2.yaml`, `scripts/compare_memory.py --fill continuous`):**
- 느린 채널: 16개 적응 채널 뒤에 4개를 더합니다. τ는 1개월–2년 로그 간격으로 고정, 입력은 b = tanh(Wx)에서 W가 고정 무작위 투영(칼럼 특징의 이동평균), 혁신 흡수도 제어도 받지 않습니다. 배우는 것은 읽는 쪽(경향 C, 판독 R)뿐입니다. D-noactor 체크포인트에서 시작하며 새 입력 열은 0이라 출발점은 D-noactor와 같습니다(테스트로 확인).
- 연속 필터 학습: 2018–19를 72시간 창(처음 24시간은 매 걸음 참값 재관측 = 채움, 뒤 48시간은 자유)으로 끊김 없이 이어 달립니다. 기억은 창 사이에서 detach(절단 역전파)하고, 손실은 모든 걸음의 GraphCast 가중 예보 오차입니다. 자유 구간이 "채워진 기억에서의 예보"를, 채움 구간이 한 걸음 필터를 가르칩니다. 창 끝에서는 재관측 없이 기억만 넘겨 이득 G가 시험 때처럼 한 걸음 혁신만 봅니다. 1 에포크(243창), 학습률 칼럼 1e-4·기억 1e-3, 발산 걸음에서 창을 끊고 기억을 0으로.
- 채움: 2018-01-01부터 2020년 각 초기 시각까지 한 번 연속 통과(30일 창, 기억만 이어 감)하고 초기 시각마다 m을 저장한 뒤 자유 예측합니다. 120시간은 §10.1의 GraphCast 틀, 28일은 지속성·기후값과 비교(초기 시각 31개, 12일 간격).

## 11단계 — 신경 연산자 묶음과 강화학습 선택 (`stage11_operator_bank/`)

**가설 (감자, 10/31 21:42–21:43):** 강화학습이 단순 딥러닝과 다른 점은 여러 네트워크 가운데 어느 것을 쓸지 고르는 데서 나오는 제어입니다. 그래서 여러 신경 연산자(neuraloperator 저장소)를 강화학습 구조로 묶습니다. 고르는 행위에는 기울기가 없으므로 보상으로만 배울 수 있고, 연산자 자체는 미분 가능한 세계 모델을 통과하는 기울기로 배울 수 있습니다. 참고: Petrovskyi & Dolgikh (2026, SmartIndustry, 결과 없는 제안)는 FNO를 세계 모델로 쓰고 행위자 손실을 λL_TD3 + (1−λ)L_FNO로 둡니다. 여기서는 세계 모델이 이미 미분 가능한 물리 코어(N1)이므로 연산자를 제어기 쪽에 둡니다.

**구현 (`models/operator_control.py`, `train/prediction_game.py`의 `hybrid` 모드, `configs/operator_game_wb2.yaml`):**
- 연산자 K = 4개는 neuraloperator 2.0의 SFNO(구면 Fourier 신경 연산자)입니다. 설정은 다음과 같습니다.
  - 격자: 코어의 Gaussian 격자(legendre-gauss SHT)
  - 폭 16, 2층, 모드 16
  - 위치 임베딩: 경도 좌표를 넣지 않고 sin(위도)만 넣습니다
  - 입력: 층 평균 T 편차, ζ, D, q(4개 층 묶음), Φ_b 편차, 변수 묶음별 마스크, sin(위도), 단계
  - 출력: T·ζ·q(4개 층)와 Φ_b의 제어장. n ≤ 10에서 자르고 9단계의 행동 단위를 곱합니다
  - 마지막 층이 0에서 시작하므로, 학습 전에는 무제어와 같습니다
- 선택: 6시간마다 세 위도대(남 < −30°, 열대, 북 > 30°, 경계는 5° 로지스틱)에서 "연산자 1–4 또는 개입 안 함" 5개 중 하나를 고릅니다. 정책은 9단계 제어기의 특징(상태와 마스크의 저차 조화 성분, 단계)을 읽습니다. 제어장은 u(x) = Σ_r w_r(위도) O_{k_r}(상태)(x)입니다.
- `hybrid` 학습: 선택은 표본으로 뽑고, 4개 멤버의 집단 정규화 보상 누적합으로 REINFORCE 합니다. 연산자는 같은 에피소드에서 고정 N1을 통과하는 정확한 기울기로 학습합니다. 손실은 λL_RL + (1−λ)L_grad, λ = 0.5입니다. 게임, 연도, 마스크, 재관측, 비용, 발산 가드는 9단계 N3와 같습니다(2018–19 학습, 2020 시험, 100회 갱신).

**팔:**
- O-sel: 선택은 RL, 연산자는 기울기 (주 팔)
- O-soft: 같은 4개를 softmax 가중치로 섞고 전부 기울기로 학습. 선택 없는 전문가 혼합으로, 딥러닝 대조군입니다
- O-1: 연산자 하나, 기울기
- 비교 기준: N3(9단계 MLP 제어기, rl), nudging(직접 삽입, 절반 세기), 무제어

평가 knock-out은 무작위 선택, 항상 연산자 1, 항상 개입 안 함, 상태 숨기기입니다. 위도대별 선택 비율과 초기 시각·단계별 선택도 기록합니다.

**예측(사전 등록):**
- R1: O-sel이 O-soft와 O-1보다 2020 가려진 24h 오차를 3% 이상 낮춥니다. "선택"이 중요하다는 감자의 가설입니다.
- R2: 무작위 선택이 O-sel의 무제어 대비 이득 가운데 절반 이상을 잃습니다. 선택에 정보가 있다는 뜻입니다.
- R3: 연산자가 나뉘어 쓰입니다. 선택한 연산자와 마스크 종류 또는 위도대 사이의 상호정보량이 0.1 nat 이상입니다.
- R4: O-sel이 N3보다 3% 이상 낮습니다. 장(field) 대 장 연산자가 저차 조화 성분 MLP보다 낫다는 뜻입니다.
- R5: O-sel의 선택 엔트로피가 학습 중 줄어듭니다. 균일한 선택에서 시작합니다.

R1이 지지되지 않고 O-soft가 같거나 나으면, 이 판에서는 선택보다 혼합이 낫다는 뜻입니다. 그때 다음으로 볼 것은 선택의 단위입니다. 위도대가 너무 크면 12개 패치나 마스크 영역 단위로 시험합니다.

**설치:** `pip install neuraloperator torch-harmonics==0.7.4` (`pyproject.toml`의 `operator`). torch-harmonics 0.9는 torch < 2.15를 요구하고, 0.7.4의 구면 조화 변환은 순수 Python이라 torch 2.15에서 작동합니다(확인함).

## 12단계 — 능동 관측: 관측 위치를 고르는 행동 (`stage12_active_obs/`)

**가설 (감자, 11/01 10:04–10:07):** "Action적 요소를 추가해서 진정한 의미의 월드 모델로 강화구조를 만들고 싶다. 특히 기후예측이라는 목적을 가지고." 대기는 행동으로 바꿀 수 없지만 관측 체계는 바꿀 수 있습니다. 행위자가 어디를 관측할지 고르고, 기억 모델이 그 관측을 동화(10단계 사후 규칙)해 나머지를 예측합니다. 보상은 예보 오차이므로 행위자는 "이 모델과 이 기억에게 어느 관측이 가장 값진가"를 배웁니다. 기후 예측의 목적에서는 관측의 가치가 기억(느린 변수)을 채우는 곳에 있어야 한다는 것이 검증 대상입니다. 세 대안(능동 관측 / 연산자 선택 = 11단계 / 강제력 시나리오 개입) 가운데 결정 카드로 능동 관측을 골랐습니다.

**구현 (`train/active_obs.py`, `scripts/train_active_obs.py`, `scripts/eval_active_obs.py`, `scripts/report_active_obs.py`, `configs/active_obs_wb2.yaml`; 세계 모델 쪽은 `physics_world_model.column_inputs`로 칼럼 입력 x를 바깥에서 읽어 τ(x) 지도를 얻습니다):**
- 게임: 초기 시각의 완전 관측 스냅샷(GraphCast 초기화와 같음, 기억 0)에서 시작해 6시간마다 예보합니다. 처음 `obs_steps`번의 예보 뒤마다 규칙이 24개 등면적 패치(위도대 4 × 경도 구역 6, 위도 경계 −90/−30/0/30/90°) 가운데 n = 예산 25% = 6개를 골라 그 패치의 모든 변수를 재관측하고, 나머지는 예보 + 기억 판독 R(m)을 유지합니다(10단계 사후 규칙; 기억 없는 N1에서는 nudging α = 1). 그 뒤는 자유 예측입니다. 점수는 매 걸음 재관측 전 예보의 GraphCast 가중 전역 오차이므로 k번째 선택은 k+1 이후의 오차로 보상받습니다.
- 규칙: `policy`(학습), `random`(같은 예산의 무작위, 통제군), `age`(가장 오래 안 본 패치: 순환 관측), `readout`(기억 판독 |R(m)|이 큰 패치: 모델 자신의 오차 추정), `tendency`(6시간 변화가 큰 패치), `full`(전부 관측, 상한), `none`(무관측 = 콜드 자유예보, 하한).
- 정책: 패치마다 공유 MLP(29 → 64 → 64 → 1)가 로짓을 냅니다. 입력은 패치 안의 예보 6시간 변화 RMS(변수 묶음 6개), 기억 판독·기억 상태 RMS, log τ 평균, 나이(마지막 관측 뒤 걸음 수), 같은 특징의 전구 평균(문맥), 위도 사인, 걸음 one-hot입니다. 선택은 Plackett–Luce 분포의 비복원 표본(Gumbel-top-k), 시험에서는 로짓 상위 n개. 마지막 층이 0에서 시작하므로 학습 전 정책 = random입니다.
- 학습: 세계 모델은 얼립니다(7단계처럼 C만 학습). 반복마다 2018–19의 한 시점에서 8개 에피소드(60시간 = 36시간 동안 관측 선택 6번 + 24시간 자유)를 표본 추출하고 선택마다 집단 정규화 보상 누적합(7·9·11단계의 `reward_to_go_advantages`)으로 REINFORCE 합니다. 100회 갱신, 학습률 1e-3 코사인, 폭주한 멤버는 상한 10점이고 마지막 유한 걸음까지만 기여합니다.
- 평가(2020, 규칙끼리 초기 시각마다 같은 난수로 짝지음): ① 게임 120시간(48시간 동안 선택 8번 + 72시간 자유, GraphCast 리드), 31개 초기 시각, 예산 12.5/25/50%, 기억 모델의 7개 규칙 + N1(nudging)의 policy/random/full/none. ② 기후 틀(`eval_memory_climate`와 같은 채점): 예산 관측 10일 뒤 4주 자유, 주평균을 ERA5·기후값과 비교, 8개 초기 시각. 기록: 패치별 선택 빈도와 그 엔트로피, 기억의 패치별 log τ 지도와 판독 지도.

**원인 절제:** 예산 12.5/25/50%(선택의 가치가 예산에 따라 어떻게 변하는가), P-nomem(기억 지도를 못 보는 정책: 정책이 기억을 읽어야 하는가; N1에도 공정한 정책), 기억 모델 대 N1(같은 규칙 아래 기억이 관측을 더 오래 유지하는가), 고정 규칙 셋(학습이 필요한가).

**판정 규칙 (사전 등록):**
- A1 선택의 가치: 2020 게임에서 policy의 자유 구간(54–120h) 전역 오차가 random보다 5% 이상 낮음(부트스트랩 95% 구간이 0을 넘지 않음).
- A2 학습의 필요: policy가 가장 좋은 고정 규칙(age·readout·tendency)보다 3% 이상 낮음. 고정 규칙이 policy와 같으면 "선택에 정보는 있으나 학습은 필요 없음".
- A3 기억과의 결합: policy의 패치별 선택 빈도와 기억의 패치별 log τ 지도의 Spearman 상관 ≥ +0.3(기억이 오래 남는 곳을 더 자주 봄). 부호가 반대면 "빨리 잊는 곳을 자주 본다"로 따로 보고.
- A4 기억 모델 대 N1: 같은 policy(기억 지도 입력은 N1에서 0) 아래 기억 모델의 자유 구간 오차가 N1 + nudging보다 5% 이상 낮음.
- A5 기후: 기후 틀에서 policy의 1–2주 주평균 오차가 random보다 3% 이상 낮음. 3–4주는 보고만(C4처럼 어느 규칙도 기후값을 넘지 못하리라 예상).
- A6 불변성: 2018–19(학습 연도) 15개 초기 시각과 2020의 패치별 선택 빈도의 순위상관 ≥ 0.7(정책이 연도가 아니라 규칙을 배움).

**시간 (KST):** 구현·테스트 ~2h(11/01 12:30 완료), 학습 P ~1.7h(1스레드 부업, 체인 4 뒤 ~13:30부터), 게임 평가 ~1.5h, 기후 평가 ~1.5h, P-nomem 학습·평가 ~3h → 보고 11/02 저녁(앞당겨지면 11/01 밤).
